# FlarePanel

FlarePanel is open-source web and product analytics that runs entirely on Cloudflare: Workers receive events at the edge, each project's events live in its own Durable Object, raw events are archived to R2, and accounts live in D1. There are no servers or databases to run.

It is a fork of [OpenPanel](https://github.com/Openpanel-dev/openpanel) and speaks the same tracking protocol, so the OpenPanel SDKs you may already use work by pointing them at FlarePanel.

:::info
The hosted service is open, and every account starts with a 30-day free trial. For what each part does today, see [What works today](/getting-started/status).
:::

## Start here

- [Quickstart](/getting-started/quickstart): create a project and send your first event in a few minutes.
- [Coming from OpenPanel](/getting-started/openpanel): keep your SDK, change one URL.
- [Install](/sdks/script-tag): script tag, JavaScript and React, Next.js, server SDKs and the HTTP API.
- [Self-hosting](/self-hosting): run the same code on your own Cloudflare account, or with Docker on your own server.

## How it works

```
your site or app ──► Worker at the nearest edge ──► project Durable Object ──► R2 archive
   (SDK, op1.js)        (auth, bot check, geo)       (events, sessions,        (ndjson.gz
                                                      daily rollups)            per hour)
```

Read more in [Architecture](/self-hosting/architecture).
