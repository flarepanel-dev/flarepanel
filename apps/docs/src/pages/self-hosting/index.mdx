# Self-hosting

FlarePanel is one codebase: the hosted service and a self-hosted install run the same code. Self-hosting puts everything in **your** Cloudflare account, so your events never leave it and you pay Cloudflare directly for what you use.

## Self-hosted and hosted

Like OpenPanel, one switch decides which one an install is: `SELF_HOSTED`, set on both Workers ([Deploy](/self-hosting/deploy#point-it-at-your-domains)).

| | Self-hosted (`SELF_HOSTED` set) | Hosted flarepanel.dev |
|---|---|---|
| Price | Free; you pay Cloudflare for what you use | Plans by monthly events, 30-day trial (billing opens later; early access is free) |
| Features | Everything | Everything, in every plan |
| Events | No limit | Your plan's events; email at 80%, never an overage charge |
| Session replay | Every organization, 10,000 recorded sessions a month each by default (changeable) | Trial: 500 a month; plans: one recorded session per 100 plan events (1,000 to 100,000) |
| AI chat | With your own OpenAI or Anthropic key | Included |
| Billing pages | Hidden | Shown |

Limits exist so that nobody's bill grows by surprise: on Cloudflare every request and every stored replay chunk is metered. Set a [budget alert](/self-hosting/operations#alerts-in-your-cloudflare-account) on your account as well.

## What you need

- A Cloudflare account on the **Workers Paid** plan. The API bundle is about 4.6 MB compressed, above the free plan's 3 MB limit.
- A domain on Cloudflare DNS for the API and dashboard, for example `api.example.com` and `analytics.example.com`.
- [Bun](https://bun.sh) and the repository.

## What gets created

| Resource | Used for |
|---|---|
| Worker `flarepanel-api` | Tracking, the dashboard API, auth, jobs |
| Worker `flarepanel-dashboard` | The dashboard |
| D1 database | Accounts, organizations, projects, clients |
| D1 database `flarepanel-geo` (optional) | IP ranges for locating server-side events and the IP lookup tool (DB-IP City Lite) |
| Durable Objects | One per project: events, sessions, rollups, live sockets; plus rate limits and locks |
| R2 bucket | Raw event archive, AI prompt text, import copies (optional; without it events are kept 30 days and imports are unavailable) |
| Queues | Background jobs and their dead-letter queue |
| Email Service binding | Account emails (optional) |
| Worker Loader binding | Runs JavaScript webhook templates in a sandboxed Dynamic Worker: no network, 50 ms CPU. One template counts as one Dynamic Worker a day (1,000 a month included) |

A one-command setup is planned. Until then, follow [Deploy to Cloudflare](/self-hosting/deploy).
