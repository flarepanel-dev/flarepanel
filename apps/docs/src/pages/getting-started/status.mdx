# What works today

What FlarePanel does today, part by part, with the limits that apply. The table describes the hosted service and a Cloudflare install; a server install differs in [a few places](/self-hosting#choose-how-to-self-host).

| Area | Status |
|---|---|
| Accounts, organizations, projects, clients | Works |
| Tracking: `track`, `identify`, `increment`, `decrement`, revenue | Works |
| Script tag `op1.js`, web, Next.js and server SDKs | Works |
| Onboarding "first event", event list, live event and visitor sockets | Works |
| Overview numbers and chart (visitors, sessions, bounce rate, duration, page views, revenue) | Works, in your project's timezone, by minute, hour, day, week or month |
| Top pages, entry and exit pages, sources, UTM, countries, devices, browsers, map | Works |
| Overview filters | Work over all history (older than 90 days read from the R2 archive) |
| Live card (last 30 minutes) and Sessions page | Works (Sessions page: last 90 days) |
| Profiles: list, search and profile page | Works |
| Account emails (sign-up verification, invites, password reset) | Works |
| Groups: list, group pages, members, `group.*` filters and breakdowns | Works |
| Cohorts: event and property cohorts, refreshed every 30 minutes, cohort filters in reports | Works (event cohorts read the last 90 days plus the R2 archive) |
| AI analytics: cost, tokens, latency, errors, traces and calls, prompt and response text | Works (text kept 30 days) |
| Location of server-side events that pass the visitor's IP (`__ip`) | Works, with IP geolocation by [DB-IP](https://db-ip.com) |
| Bot traffic: kept out of analytics, recent bot hits listed through the API | Works (up to 5,000 a project a day, kept 30 days) |
| Session replay (web SDK, `sessionReplay: { enabled: true }`) | Works, kept 30 days, with a monthly number of recorded sessions per organization ([details](/self-hosting#self-hosted-and-hosted)) |
| Report builder: line, bar, area, pie and metric charts with breakdowns, filters and formulas | Works over all history (older than 90 days read from the R2 archive) |
| Funnels (with breakdowns and time to convert) and retention cohorts | Work over all history (older than 90 days read from the R2 archive) |
| Faster long-history reports for very large installs (self-hosted, opt-in) | [Advanced analytics](/self-hosting/advanced-analytics) |
| Conversion, user flow (Sankey) and distribution charts | Work over all history (older than 90 days read from the R2 archive) |
| Notifications: event and funnel rules, in-app, email, Slack and webhooks (including JavaScript templates, run in a sandboxed Dynamic Worker) | Works |
| Insights (daily changes in referrers, countries, devices, entry pages and pages) and referrer spikes on the overview chart | Works |
| REST API (`/insights`, `/export/events`) and MCP server for AI assistants | Works |
| Chat assistant, report drafts, natural-language filters, insight summaries | Works with your own OpenAI or Anthropic key ([how](/features/ai-keys)) |
| SEO page (Google Search Console) | Works with a Google OAuth client ([setup](/self-hosting/deploy#google-search-console-seo-page)) |
| Imports from Umami (CSV), Mixpanel and Amplitude | Works |
| Exports to S3, S3-compatible storage (R2, MinIO) and Google Cloud Storage | Works, every minute |
| Self-hosting on your own Cloudflare account | Manual deploy works; a one-command setup is planned |
| Self-hosting with Docker on your own server | Works, with published images ([guide](/self-hosting/server)) |

Follow progress on [GitHub](https://github.com/flarepanel-dev/flarepanel).
