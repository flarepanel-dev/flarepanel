# What works today

FlarePanel is in early access. This page is updated as parts move over from OpenPanel's ClickHouse-based stack to Cloudflare.

| Area | Status |
|---|---|
| Accounts, organizations, projects, clients | Works |
| Tracking: `track`, `identify`, `increment`, `decrement`, revenue | Works |
| Script tag `op1.js`, web, Next.js and server SDKs | Works |
| Onboarding "first event", event list, live event and visitor sockets | Works |
| Overview numbers and chart (visitors, sessions, bounce rate, duration, page views, revenue) | Works, in your project's timezone, by minute, hour, day, week or month |
| Top pages, entry and exit pages, sources, UTM, countries, devices, browsers, map | Works |
| Overview filters | Work over the last 90 days of events |
| Live card (last 30 minutes) and Sessions page | Works |
| Profiles: list, search and profile page | Works |
| Account emails (sign-up, invites, password reset) | Works |
| Groups and session replay | Accepted, not stored yet |
| Report builder: line, bar, area, pie and metric charts with breakdowns, filters and formulas | Works over the last 90 days of events |
| Funnels (with breakdowns and time to convert) and retention cohorts | Work over the last 90 days of events |
| Conversion, user paths (Sankey), distribution charts, insights, notifications | Not yet |
| Self-hosting on your own Cloudflare account | Manual deploy works; a one-command setup is planned |

Follow progress on [GitHub](https://github.com/flarepanel-dev/flarepanel).
