# FlarePanel brand

Brand kit v2, **Photon**: a panel that catches light. Machine-readable values
are in `tokens.json`; every logo file is generated by `scripts/build.ts`.

```sh
bun brand/scripts/build.ts   # rewrites brand/ and every app's copies
```

## The mark

A solid panel, 4 × 4 cells. Its cells light up in a rising staircase (a bar
chart and a flare at once), and the top step breaks away from the corner as
the flare: the moment a number turns into a signal.

- Construction: a 44-unit panel of 11-unit cells, corner radius 11 (one
  cell). The flare is one cell, lifted 4.5 units up and to the right; its
  outer corner keeps the panel's radius.
- The lit cells run from Flare (bottom left) through Ember to a warm orange;
  the flare itself is Spark with a soft glow.
- Keep the gap. Without the break the mark is a generic stair icon.
- Never rotate or mirror it: the steps always rise to the right.
- Never box, outline or add effects: the panel is already the container.
- Minimum size 16 px (use `favicon.svg`, which drops the glow).

## Files

| File | Use |
|---|---|
| `mark.svg` | The mark on dark surfaces (graphite panel) |
| `mark-light.svg` | The mark on light surfaces (pale panel) |
| `mark-mono-paper.svg` / `mark-mono-ink.svg` | One colour, for stamps, embossing and single-colour print |
| `icon.svg` / `icon-light.svg` | The mark on an ink or white app-icon tile |
| `favicon.svg` | Small sizes: tighter crop, no glow |
| `wordmark-dark.svg` / `wordmark-light.svg` | Mark and name for dark and light backgrounds |
| `icon-512.png` | Raster icon where SVG is not accepted |
| `wordmark-text.path` | The outlined name (Geist SemiBold, weight 640, tracking -3.5%) |

The build also writes each app's copies: favicons, `favicon.ico`
(16/32/48/64), PWA icons, `apple-touch-icon.png` (180 px, square and opaque
because iOS rounds the corners), the email logo (`apps/landing/public/logo.png`)
and the 1200 × 630 social images for the website and docs.

## Colour

| Role | Value | Use |
|---|---|---|
| Flare | `#FF3D6E` | Interaction: links, focus rings, selection, the active marker |
| Ember | `#FF6A4D` | Data: the lead chart series, KPI bars, the current-period line |
| Spark | `#FFB547` | Live: online-now dots, the live card, the newest event |
| Ink | `#0D0D10` | Page ground on dark, text and primary buttons on light |
| Paper | `#F9FAFE` | Text and primary buttons on dark |
| Up / Down | `#3CCB7F` / `#EF5A5F` | Deltas, always with an arrow |

Chart series order: ember, sky, spark, teal, violet, lime, slate, flare,
blue, orchid, sea, green, blush. Mirrored in `apps/start/src/styles.css`
(`--chart-0..12`) and `packages/core/src/modules/report/report.constants.ts`.

### Rules

1. **One job per colour.** Flare is for things you can click or that have
   focus, Ember is data, Spark is live. Do not swap them.
2. **The gradient belongs to the light.** The Flare → Ember ramp appears in the
   mark, in data bars (lit from the base like the logo's panel) and in one
   warm stage light behind the product. Not on buttons, text or borders.
3. **Down is its own red** (`#EF5A5F`), never a data colour, and always with an
   arrow.
4. **Primary buttons stay paper on ink** (ink on white in light themes).
5. **Not Cloudflare.** FlarePanel runs on Cloudflare but is not a Cloudflare
   product: never use Cloudflare's logo or name as branding.

## Type

Geist everywhere: SemiBold/Bold with tight tracking (-0.035 to -0.045em) for
display, Regular for text, Geist Mono for numbers, code and measurements.
The dashboard and the website use the same families.

## Name

Write it **FlarePanel**: one word, capital F and P. The domain is
`flarepanel.dev`.
