# FlarePanel brand

Basic v1 brand. Keep it simple until we do a proper identity pass.

| File | Use |
|---|---|
| `logo-mark.svg` | App icon, favicon source, avatars |
| `logo-mark-512.png` | Raster mark for places that need PNG |
| `wordmark-light.svg` | Mark + name on light backgrounds |
| `wordmark-dark.svg` | Mark + name on dark backgrounds |

## Mark

Three rising bars (the analytics panel) and a spark (the flare) on a warm
gradient tile. Do not recolor the bars or stretch the tile.

## Colors

| Name | Hex | Use |
|---|---|---|
| Flare | `#FF5B1F` | Primary brand color, links, "Panel" in the wordmark |
| Ember | `#E8361A` | Gradient start |
| Amber | `#FFA53A` | Gradient end |
| Ink | `#18181B` | Text on light |
| Snow | `#FAFAFA` | Text on dark |

Flare is deliberately not Cloudflare's orange: FlarePanel runs on Cloudflare
but is not a Cloudflare product.

## Name

Write it **FlarePanel** (one word, capital F and P). The domain is
`flarepanel.dev`.

Dashboard icons in `apps/start/public` (`logo.svg`, `favicon.ico`,
`logo192.png`, `logo512.png`, `apple-touch-icon.png`) are generated from
`logo-mark.svg`.
